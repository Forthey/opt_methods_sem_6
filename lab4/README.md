# Задача минимизации методами различных порядков

- Решить задачу градиентным методом 1го порядка наискорейшего спуска (точности 0.1, 0.01, 0.001)
- Ту же задачу решить градиентным методом второго порядка Ньютона (шаг = 1)
- Решить задачу без использования производных (Хаукинса-Джибса)
- Для метода 1го порядка показать вычислительным экспериментом ортогональность звеньев градлиентной ломаной на двух последовательных итерационных шагах
- Также решить задачу таким образом: сначала методом 1го порядка приближаемся к точке оптимума, а потом уточняем её методом 2го порядка. Аналогично с методом Хаукинса-Джибса (вместо метода 1го порядка)
- Не забыть про условия сходимости методов
- Построить линии уровней функции целей, проходящие через заданную точку (опционально)

## Функция

$$ x^2 + (y + 1)^2 + e^{x - 1} + e^y $$
